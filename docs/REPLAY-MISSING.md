## 一、论断核对（逐条对着产物，不靠印象）

**论断**：*"按它自己的 G2，'复活'（重放）那张卡还是空的。记账和结晶都做了，重放没转。⇒ 循环还差最后一圈。"*

**核对结果：成立。**

```
DNA.md:7   ## G2 · 循环转一圈才算活
DNA.md:8   **经历 → 记账 → 结晶 → 重放**。有经历无结晶、有结晶无重放 = 空转 = 失败。
SPEC.md:27 经历 → 记账(ledger) → 结晶(经济门槛+三要件) → 重放(注入) → 下一任务
```

| 圈 | 有没有机械 |
|---|---|
| 经历 | ✅ （采用者的 own loop） |
| **记账** | ✅ `ledger/hits-2026.jsonl`（append-only，kind 分类） |
| **结晶** | ✅ `decisions/ADR-*.md`（`id/seq/hard/applies-to/check/redtest/revisit-on/expires-on`） |
| **重放** | ❌ **只有定义** |

**证据**：`grep -rl "重放|replay"` ⇒ **只有 `DNA.md` 与 `SPEC.md`**；
`tools/` 只有 `validate / check-baseline / claim-check / spec-lint` ⇒ **没有任何重放类机制**；
`fixtures/` 里 6 个夹具全是"某个文件必须/不得……" ⇒ **没有一个是关于"教训有没有回到下一个任务"的**。

**⇒ 结论：G2 的第四圈是**定义完备、实现为零**。按它自己的判据（"有结晶无重放 = 空转 = 失败"），
**循环目前停在第三圈。** 论断成立，且说法与产物一致。**

## 二、★ 但要点名一件更重要的事：**它不是"没做"，是"没法被证伪"**

**注意 `SPEC.md:27` 把重放写作「重放（注入）」。**
⇒ **重放 = 把结晶出的教训**注入到下一个任务**。**
**⇒ 而"注入"是**采用者的机制**（agent 的 prompt/上下文装配），不是 phyt-DNA 的。**

**⇒ 所以 phyt-DNA 能做的、也是唯一该做的，是给出**重放的可证伪形式**：**

```
① 契约：什么叫"这条教训被重放过"（一次注入？N 次？注入到哪一段？）
② 闸门：一条 crystallized 教训在后续 N 个任务里【没有】被注入过 ⇒ 红
③ 账本 kind：replay（哪条教训、哪次任务、注入的证据）
```

**⇒ 不做这三件，"重放"就永远只能靠人相信它发生了 —— 那正是本方法论最反对的东西。**

## 三、★★ 它与生态里的一个真实缺陷是**同一类**

2026-10-09 在 Helix 生态里实测到：**身份块（gene_lock + 工具清单）在活的 gRPC 通道上被丢弃** ⇒
模型答 "Qwen" 而不是 "Dash"，且 523 轮里字面回答 `no calls planned` —— **因为没有人告诉过它有哪些工具**。

**⇒ 那是**同一个形状**：某样东西**被算出来了**（教训/身份/工具清单），但**没有到达该到达的地方**。**
**⇒ 而在生态侧，修法是**一条通道上的一个字段**（`ReasonRequest.system = 5`），不是"新增一套系统"。**
**⇒ 所以"重放"这一圈，多半也不是"要建一套新东西"，而是**找到那条"从仓库到任务"的路并对齐它**。**

## 四、最小可证伪的一步（建议）

| 步 | 做法 | 判据（必须能红） |
|---|---|---|
| **1** | 给 `ledger` 加 `kind: replay`（schema 已允许扩展 `kind` 枚举 —— 一条新枚举值即可） | — |
| **2** | 一个 gate：`ADR-…-lesson-must-be-replayed`（`hard: true`，`applies-to: ["decisions/*.md"]`）—— 对每条 `revisit-on` 未过期的结晶，检查它在最近 N 条 `kind: replay` 里出现过 | **正例夹具**：一条结晶 + 空的重放账 ⇒ **红**；**反例**：`touch` ⇒ **结论不变** |
| **3** | `redtest` 写进 ADR（本仓已有此字段）⇒ `validate.sh --probe` 能自动跑 | `--probe-all` 里它必须是 RED 且反例守住 |

**⇒ 这三步做完，"重放"就从**定义**变成**可证伪** —— 而 G2 的四圈才第一次**全部可被机械检查**。**
