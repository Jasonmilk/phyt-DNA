# 可选推进档（stance: optional）

> 性质：**可被忽略的条目**。不是判据、不是强制、不是前置、不是默认，不构成授权。
> 生长态选项：可弃用、不读也合规。

## 它指向什么

helix-mind 侧的三个入口（此处只给指针，不给全文）：

- 判例索引（自判定档的先例，含「改判了哪句 + 覆盖链位置」）
- 「不拍」三态：稳态（低频守护）｜削未知（① 直做报结果）｜元层饱和（具名转守护）
- 探测模板：构造 vs 真跑分栏 · 退出条件 · 只列形态不选形态 · 不写已实施/已验收

## 怎么用

- 适用 ⇒ 引用，**不复制、不改写、不重验**。
- 不适用 ⇒ 具名一句「哪条不适用 + 为什么」+ 覆盖链位置。
- **没查、没读、没用，也合规**。

## 作用域

不预设：本会话 / 今日 / 单任务 / 某次推进 / 单项目皆可；枚举非穷尽，**带时刻即失效**。

## 它不解锁什么

不改任何判据、不动账本语义、不销红、不解 M7、不裁封存两拍、不解锁 5010 (c)；
本文件的存在不改变任何 gate 的判定结果。
